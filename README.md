## 🎯 设立宗旨

在这个信息过载、二手营销号与垃圾噪音泛滥的时代，建造者最稀缺的资源是注意力。

**零噪音（Zero Noise）** 致力于维护一份极度克制、只保留第一手信息源的纯净清单：
1. **一手优先**：只收录官方发布管道、核心开发者个人博客、开源项目 Release 与极客社区；
2. **严控数量**：宁缺毋滥，每个细分领域只保留最不可替代的 3~5 个信源；
3. **即拷即用**：提供一键导入的 `feeds.opml`，配合任意 RSS 阅读器即可离线阅读。

## 📑 核心信源导航

### 1. 🤖 AI 与模型一线工程
- **OpenAI News & Research** - 官方研究更新与技术文档
- **Anthropic News** - Claude 官方技术发布与安全研究
- **Hugging Face Daily Papers** - 每日高引学术论文精选
- **Simon Willison’s Weblog** - LLM 实用工程、Prompt 注入防御与个人实测

### 2. ⚡ 架构与基础设施
- **Cloudflare Blog** - 边缘计算、网络协议与底层架构实战
- **Fly.io Phoenix Files** - 深入 Linux 内核、容器化与分布式系统
- **Antirez Weblog** - Redis 作者 Salvatore Sanfilippo 的个人思考与架构沉淀

### 3. 🛠️ 独立开发与微工具
- **Paul Graham Essays** - 黑客与画家、创业心智模型
- **Derek Sivers Blog** - 极简主义商业与生活哲学
- **Dan Luu** - 扎实的工程性能实测与深度长文随笔

## 📮 提交优质信源

收录准则：

- 拒绝任何洗稿、纯搬运、营销引流号；
