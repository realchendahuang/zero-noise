## 设立宗旨

在这个信息爆炸、二手营销号与垃圾噪音泛滥的时代，建造者最稀缺的资源是注意力。

零噪音（Zero Noise）坚持极度克制的一手信息源过滤原则：
1. 一手优先：只收录官方发布渠道、核心开发者博客、开源项目 Release 与极客社区；
2. 严控数量：宁缺毋滥，每个细分领域只保留最不可替代的 3 到 5 个信源；
3. 开箱即用：提供全量打包好的 feeds.opml 文件，导入阅读器即可离线阅读。

## 一键导入订阅（OPML）

仓库根目录提供打包好的 feeds.opml 文件。

推荐配套 RSS 阅读器：
- NetNewsWire（macOS / iOS 开源免费首选，纯本地无云端延迟）
- Inoreader（跨平台全功能订阅）
- Readwise Reader（长文稍后读与标注工作流最佳搭档）

## 提交优质信源

欢迎在 Issues 或 Pull Requests 提交你私藏的高信噪比信源。

收录准则：
- 必须是作者本人的原创思考或官方一手发布；
- 拒绝任何洗稿搬运、商业推广软文号；
- 优先支持提供标准 RSS/Atom 源的独立站点。
